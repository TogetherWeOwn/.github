# Support

- **Bug reports and feature requests:** open an issue using the templates.
  Search existing issues first; duplicates are closed.
- **Questions about contributing:** read `CONTRIBUTING.md` first, then ask on the issue.
- **Security issues:** see `SECURITY.md`. Never file them as public issues.
- **CI change gating:** see `CI-STANDARD.md` for which jobs run on your pull request.
